BACKEND TREINAMENTO LMS


--------------------------------------------------
1. LINGUAGEM E VERSÃO
--------------------------------------------------
Python 3.12 (imagem base: python:3.12-slim no Dockerfile)

--------------------------------------------------
2. DEPENDÊNCIAS
--------------------------------------------------
Arquivo: requirements.txt (raiz do projeto) — 23 pacotes.
Principais: FastAPI, SQLAlchemy (async), asyncpg, Alembic,
pydantic v2, python-jose, passlib.

No Dockerfile já roda: pip install -r requirements.txt

--------------------------------------------------
3. BUILD DA APLICAÇÃO
--------------------------------------------------
Não é Java nem Node — é Python puro.
O build é o próprio Docker:

    docker build -t treinamento-backend .

O Dockerfile faz:
  - instala deps do sistema (gcc, libpq-dev)
  - copia o código
  - pip install -r requirements.txt
  - EXPOSE 8080
  - CMD: uvicorn app.main:app --host 0.0.0.0 --port 8080

--------------------------------------------------
4. TESTES
--------------------------------------------------
Não existe "mvn verify" nem "node build" (sem Java/node).
Testes rodam com pytest e exigem um PostgreSQL de teste
(variável TEST_DATABASE_URL), então rodam em pipeline com
banco, não no build da imagem.

Comando: pytest

--------------------------------------------------
5. HEALTH CHECK (para Kubernetes/GKE)
--------------------------------------------------
Liveness:  GET /health/live
Readiness: GET /health/ready

--------------------------------------------------
6. PORTA
--------------------------------------------------
8080 (já exposta no Dockerfile)

--------------------------------------------------
